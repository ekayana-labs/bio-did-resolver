# Security Policy

## Reporting security problems

**DO NOT CREATE A GITHUB ISSUE** to report a security problem.

Please use the
[Report a Vulnerability](https://github.com/ekayana-labs/bio-did-resolver/security/advisories/new)
link with a helpful title and a detailed description of the problem.
Expect a response typically within 72 hours.

If you receive no response in the advisory, email <suraj410401@gmail.com>
with the advisory URL. Do not put exploit details in the email; keep them
in the advisory.

## Scope

Anything that makes this tool resolve a DID to a document its registry
state does not justify, encode an instruction the program would interpret
differently than the command line implies, or send a transaction the user
did not ask for. Handling of key material and keypair files is in scope.

The on-chain program and the resolution library live in separate
repositories; reports about them are still welcome through this channel.
