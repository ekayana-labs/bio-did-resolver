# Security Policy

## Reporting security problems

Do not open a GitHub issue to report a security problem.

Please use the
[Report a Vulnerability](https://github.com/ekayana-labs/bio-did-resolver/security/advisories/new)
link with a helpful title and a detailed description of the problem.
Expect a response typically within 72 hours.

If you receive no response in the advisory, email <suraj410401@gmail.com>
with the advisory URL. Keep exploit details in the advisory and out of the
email.

## Scope

The scope is anything that makes this tool resolve a DID to a document
its registry state does not justify, encode an instruction the program
would read differently than the command line implies, or send a
transaction the user did not ask for. Handling of key material and keypair
files is in scope too.

The on-chain program and the resolution library live in separate
repositories. Reports about them are still welcome through this channel.
